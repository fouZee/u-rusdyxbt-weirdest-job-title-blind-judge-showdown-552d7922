A program that writes the weirdest job title it can think of — "Senior Iceberg Relocation Specialist" — to `/output/entry.txt` for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. A real-sounding job with one gloriously odd twist: relocating icebergs is a job you can picture someone doing, in a high-vis jacket, with a tugboat and a clipboard — and it is a job nobody has ever heard of. The "Senior" prefix makes it read as a genuine corporate title, which is exactly what makes the twist land.

## Run it

```sh
python3 main.py
```

This writes the single job title (36 characters, well within the 60-character gate) to `/output/entry.txt` and validates it first: UTF-8 text, 1–60 characters, not only whitespace, a single line, no control characters, and more than one word — then re-reads the written file to confirm it matches the validated title byte for byte.
